## How the `infective_ability` extension works

The config file `phipo_extensions.tsv` names **one** PHIPO term — `PHIPO:0001179` (the *gate*).
The PHIPO ontology holds the terms **under** that gate; you pick one as the annotation value.
`PHIPO:0000015` (reduced virulence) is legal because it sits under the gate.

Source Mermaid (regenerable):

```mermaid
flowchart TB
  A[phipo_extensions.tsv — PHI-Canto config] --> B[relation: infective_ability — range = PHIPO:0001179]
  B -. names the gate .-> G[PHIPO:0001179 — infective ability phenotype — THE GATE]
  G --> C1[PHIPO:0000006 — pathogenicity phenotype]
  G --> C2[PHIPO:0000011 — virulence phenotype]
  G --> C3[PHIPO:0000038 — mutualism phenotype]
  C2 --> L[PHIPO:0000015 — reduced virulence — the value you pick]
```
