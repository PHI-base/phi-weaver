### 2. tmux Session Setup
Established how to create a named tmux session for the vault:
```bash
tmux new-session -s PHI-Canto -c /mnt/z/OBS-PHI-Canto
```
Or from inside tmux:
```bash
tmux new-session -d -s PHI-Canto -c /mnt/z/OBS-PHI-Canto && tmux switch-client -t PHI-Canto
```
